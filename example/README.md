# haptic_feedback_example

Try each haptic type. Android also offers a usage selector and a native-constants switch. A simulator can verify calls, but judging haptic feel requires a physical device.

Flutter 3.47 or newer; Android API 24 or newer, or iOS 15 or newer.

For Android tooling and platform requirements, see the [package README](../README.md).

From this directory, select a compatible Flutter SDK with FVM, then run:

```sh
fvm flutter pub get
fvm flutter run -d <device-id>
```
